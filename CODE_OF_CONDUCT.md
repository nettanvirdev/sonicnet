# Code of conduct

SonicNet follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be kind, assume good intent, keep criticism about the work, and make the project a
welcoming place for people of every background and experience level. Harassment, insults and
personal attacks aren't tolerated in issues, discussions, pull requests or anywhere else the
project lives.

Report unacceptable behaviour privately to the maintainer through
[GitHub](https://github.com/nettanvirdev). Reports are handled confidentially.
